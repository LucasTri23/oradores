Importar do Firebase antigo

Use uma vez para trazer territórios, cartões, dirigentes, mensagens e campanhas da versão antiga.
Cole as mesmas credenciais que você usava antes. Os dados atuais daqui serão substituídos pelos do Firebase.

Dirigentes · WhatsApp

Cadastre os dirigentes. Os botões aparecem em cada território.

Código país + DDD + número (ex: 5531999998888)

Preenche nome e número. A lista fica em Início → Pessoas.
